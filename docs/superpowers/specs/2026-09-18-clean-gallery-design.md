# Чистые карточки и большая галерея

В списке остаются фотография, название и цена. Карточка целиком открывает набор.
Убираются серия/артикул, магазин, подсказки о неделях, отдельные кнопки покупки
и выбора цели. Механика целей удаляется из интерфейса и подбора; старое поле
сохранения принимается для совместимости, баланс и покупки сохраняются.

Окно набора занимает экран: название сверху, большая фотография на всю ширину,
стрелки/свайп/клавиши для переключения и счётчик фотографий. Снизу цена и «Купить»
с «Закрыть». Если денег не хватает, остаются недостающая сумма и «Закрыть».
При покупке баланс списывается один раз, набор переходит на полку, окно показывает
успешную покупку. На полке тоже можно открыть фотографии купленного набора.

Приоритетный источник фотографий — официальный LEGO; дополнительные ракурсы
и недоступные у LEGO снимки берутся со страниц «Детского мира» и «Мира кубиков».
Данные привязаны к номеру набора. Проверяется соответствие артикулу, сохраняются источники. Изображения
хранятся в проекте, дополнительные фото загружаются при открытии набора и кэшируются.
Исходное встроенное фото доступно сразу и без сети. При недоступном дополнительном
фото остаётся работающий просмотр без пустого экрана. В резервной HTML-копии
сохраняются основные фото всех наборов; дополнительные доступны с опубликованного
сайта при наличии сети. Файл в первую очередь служит резервной копией прогресса.

Проверить: миграцию старой цели, покупку/недостаток денег/повторную покупку,
стрелки/клавиши/свайп/счётчик, закрытие, галерею купленного набора, отказ загрузки,
планшет в обеих ориентациях и телефон. После локальной проверки публикуется
обновление на прежнем GitHub Pages; кэш приложения получает новую версию.

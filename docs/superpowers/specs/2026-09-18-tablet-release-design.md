# Публикация «Тим · Моя копилка»

Пользователь просит восстановить описание существующей игры, проверить её на планшете,
опубликовать код в `0range/tim-kopilka` и дать рабочую ссылку. Подтверждено: прогресс
хранится на одном планшете, переносится резервной копией в файл.

Сохраняем существующую игру и каталог: 152 NINJAGO, 4 Harry Potter, встроенные фотографии,
начальные 1 800 ₽, 300 ₽ за неделю, три исходных набора, заработок и подарки.
Один автономный HTML без сборки публикуется как `index.html` на GitHub Pages.
Облачная синхронизация и сервер не требуются. Скачанный HTML работает без сети.

Автосохранение должно восстанавливать баланс, дату, покупки, цель, историю, настройки,
выполненные дела, продажу велосипеда, остаток дней, генератор событий, незавершённые
начисления, выбранную вкладку и страницу каталога. Сброс требует подтверждения и
возвращает к начальным настройкам, оставляя только три исходных набора.
Отмена сброса ничего не меняет. После перезагрузки сброс сохраняется, в том числе
в скачанной игре. Некорректный импорт не должен заменять текущую игру или ломать запуск.
Ошибка записи показывается заметно, резервная копия остаётся доступной в «Для папы».

Проверка: Chromium и WebKit, размеры планшета в двух ориентациях и узкий экран;
сохранение после перезагрузки, покупка, заработок, неделя/месяц, незавершённое начисление,
импорт/экспорт, отмена и подтверждение сброса, повреждённые данные и недоступное хранилище.
Финальная проверка проводится также по опубликованному адресу.

Уточнение пользователя: основной запуск — ссылка и значок на домашнем экране, без
скачивания HTML. Добавляются manifest, иконки iPad/Android и service worker для
запуска после первого посещения без сети. Файловая копия остаётся необязательной.

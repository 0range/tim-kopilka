# Тим · Моя копилка

**Играть: https://0range.github.io/tim-kopilka/**

Откройте ссылку на планшете — игра сразу готова. Скачивать HTML, регистрироваться
или устанавливать что-либо из магазина приложений не нужно. Прогресс сохраняется
автоматически после каждого действия на этом устройстве.

## Значок на домашнем экране

- **iPad:** откройте ссылку в Safari → «Поделиться» → «На экран “Домой”» → «Добавить».
- **Android:** откройте ссылку в Chrome → меню ⋮ → «Добавить на главный экран»
  или «Установить приложение» (название зависит от браузера).

Дальше запускайте игру этим значком. Для первого открытия нужен интернет.
После загрузки игра и все фотографии сохраняются в браузере для запуска без сети.
Обновления сайта не сбрасывают прогресс. Добавить значок лучше до начала игры:
в некоторых браузерах сайт и приложение с домашнего экрана используют разные хранилища.

## Что это за игра

Описание восстановлено по исходному `tim-kopilka-v4.html` от 13 сентября 2026 года.
Это спокойная игра про чтение, выбор и накопления на LEGO. Деньги, работа и покупки
в игре — понарошку; настоящие заказы и платежи не создаются. Нет таймера и штрафов.

- В начале у Тима **1 800 ₽** и три уже имеющихся набора: `71828`, `71823`, `71836`.
- За каждые семь игровых дней начисляется **300 ₽**. Можно подождать неделю или
  календарный месяц; оставшиеся дни учитываются в следующем ходе.
- Помощь по дому даёт **100 ₽**, полив цветов — **50 ₽**, разбор игрушек — **150 ₽**.
  Каждое дело доступно раз в игровую неделю. Велосипед можно продать за **2 000 ₽**
  один раз за игру.
- На день рождения и Новый год приходят подарки по **1 000 ₽**. Начиная с третьей
  недели возможна находка **100 ₽** (12%, с перерывом минимум четыре недели).
  События и находки отключаются в настройках.
- В каталоге **152 NINJAGO и 4 Harry Potter**. Можно выбрать цель, накопить и купить
  набор; покупки попадают на полку, операции — в историю. Нажатие на фото открывает
  увеличенный просмотр. «Ещё наборы» листает каталог, «К моей сумме» возвращает подборку.
- Цены — сохранённый игровой снимок от **13.09.2026**: в первую очередь «Детский мир»,
  при отсутствии предложения — «Мир кубиков». Это не текущие цены магазинов.
- Дата рождения по умолчанию — **7 февраля 2020 года**, начало новой игры — дата
  первого запуска на устройстве. Возраст растёт вместе с игровой датой.

В «Для папы ⚙» меняются имя, даты, начальная сумма, недельные деньги и события.
Изменение начальной суммы и стартовой даты применяется при следующем сбросе.

## Начать заново

**«Для папы ⚙» → «Начать заново» → подтвердить.**

Сбрасываются деньги, покупки, цель, история, выполненные дела, продажа велосипеда
и игровое время. Остаются только три исходных набора. Новая игра использует значения
из настроек. Кнопка «Продолжить игру» отменяет сброс.

## Сохранение

Баланс, дата, покупки, цель, история, настройки, заработок, события, вкладка и
страница каталога сохраняются в `localStorage` после действий. Незавершённое
начисление восстанавливается при открытии и не выдаётся дважды. Сохраняется также
одна предыдущая автокопия на случай повреждения основной записи.

Для обычной игры никаких действий по сохранению не требуется. Используйте один
и тот же браузер/значок в обычном режиме. Очистка данных сайта или приватный режим
могут удалить прогресс; между устройствами он автоматически не синхронизируется.

**Необязательно:** в «Для папы» есть «Скачать мою игру» и «Загрузить игру» для
резервной копии или переноса. Копия — автономный HTML с картинками и прогрессом;
загрузить её можно через интерфейс игры. Поддерживаются корректные сохранения v2–v4.
Это дополнительная возможность, а не способ установки на планшет.

## Разработка и публикация

Сборка и зависимости не нужны:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8765/`. Для проверки с другого устройства используйте
опубликованный HTTPS-адрес; service worker требует HTTPS либо localhost.

- `index.html` — интерфейс, логика, каталог и встроенные изображения.
- `manifest.webmanifest`, `icons/` — запуск с домашнего экрана.
- `sw.js` — кэш приложения для повторного открытия без сети.
- `tim-kopilka-v4.html` — переход со старого имени на основной адрес.
- `.nojekyll` — публикация статических файлов без сборки.

GitHub Pages публикует корень ветки `main`. При изменении кэшируемых ресурсов
увеличивайте версию `CACHE` в `sw.js`. Прогресс хранится отдельно от кэша приложения.
Исходный неизменённый HTML сохранён в истории Git в коммите `9ed83a7`.
